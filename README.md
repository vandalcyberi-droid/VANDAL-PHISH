## 🌐 Tunneling

Auto-connects via `localhost.run` for free HTTPS without port forwarding.

Alternative tunnels:
```bash
# Cloudflared
cloudflared tunnel --url http://localhost:3333

# Serveo
ssh -R 80:localhost:3333 serveo.net

# Custom port
bash run.sh 8080
```
